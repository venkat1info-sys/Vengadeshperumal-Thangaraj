Key Projects & Curriculum Initiatives

Featured Case Study: Autonomous Fire-Fighting Robot

Target: Grade 8 STEM Curriculum

Project Overview

Developed specifically for Grade 8 students, the Autonomous Fire-Fighting Robot is a hands-on introduction to smart, self-guided vehicles. Built using an Arduino Uno microcontroller and a custom corrugated sheet chassis, this project challenges students to integrate sensors, motor control, and logic-based programming. It serves as an engaging, real-world model of how automated robotics can be used in hazardous environments to solve problems and improve human safety.

Grade 8 Learning Outcomes

  • Microcontroller Basics: Explain how an Arduino Uno acts as the "brain" by processing inputs and controlling outputs.
  • Sensor Logic: Demonstrate how environmental data (infrared light) is read by a flame sensor and converted into a digital signal.
  • Power vs. Logic: Understand why a motor driver (L298) is necessary to safely manage the higher power required by motors.
  • Conditional Code: Apply basic programming concepts (if/else statements) to make the robot react autonomously.
  • Fabrication: Develop practical mechanical engineering skills by cutting and building a corrugated sheet chassis.
