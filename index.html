Autonomous Fire-Fighting Robot

Grade 8 STEM Curriculum

Built using an Arduino Uno microcontroller and a custom corrugated sheet chassis, this project serves as an engaging, real-world model of how automated robotics operate in hazardous environments to improve human safety.

Project Overview

Developed specifically for Grade 8 students, the Autonomous Fire-Fighting Robot is a hands-on introduction to smart, self-guided vehicles. Built using an Arduino Uno microcontroller and a custom corrugated sheet chassis, this project challenges students to integrate sensors, motor control, and logic-based programming.

Learning Outcomes

  • Microcontroller Basics: Arduino Uno processing logic.
  • Sensor Logic: Converting infrared data to digital signals.
  • Power vs. Logic: Safely managing L298 motor drivers.
  • Conditional Code: If/else statements for autonomy.
  • Fabrication: Practical mechanical engineering & chassis building.
