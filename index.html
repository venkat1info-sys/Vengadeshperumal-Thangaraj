Autonomous Fire-Fighting Robot

The Autonomous Fire-Fighting Robot is a smart, self-guided vehicle designed to detect and extinguish small fires. Built using an Arduino Uno microcontroller and a custom corrugated sheet chassis, this project demonstrates the practical application of sensors, motor control, and basic programming. It serves as a working model for how robotics can be used in hazardous environments to improve safety.

Working Mechanism

  • Detection: Continuously scans the environment for specific infrared fire wavelengths.
  • Signal Processing: Flame detection sends a HIGH logic signal to the Arduino.
  • Navigation Halt: Arduino triggers L298 Motor Driver to halt the BO motors at a safe distance.
  • Extinguishing: L298 activates a water pump, shooting a stream until IR light is completely eliminated.
  • Reset: Shuts off pump and resumes area scanning.

Skills Demonstrated

  • Circuit Design: Safe routing of power/logic between microcontrollers, high-current drivers, and low-current sensors.
  • Algorithmic Logic: Complex conditional code enabling autonomous environmental reaction.
  • Mechanical Fabrication: Custom chassis assembly from raw materials supporting weight/movement.
  • Hardware Debugging: Calibrating sensor sensitivity to prevent false-alarms in dynamic environments.
